# Contributing

Gracias por tu interés en contribuir a Carpooling UAL.

## Flujo de trabajo

1. Crea una rama desde `dev`: `git checkout -b feat/nombre-funcionalidad`
2. Haz commits siguiendo Conventional Commits.
3. Push de la rama: `git push origin feat/nombre-funcionalidad`
4. Abre un Pull Request a `dev`.
5. Espera a la revisión y a que el CI pase.
6. Mergea el PR (Squash and merge).

## Convenciones

- Commits: [Conventional Commits](https://www.conventionalcommits.org/)
- Ramas: `feat/`, `fix/`, `docs/`, `chore/`, `refactor/`, `test/`, `ci/`
- Código: ver `docs/manual-estilo.md`
- Git: ver `docs/manual-git-y-convenciones.md`

## Reportar bugs

Abre un issue con la plantilla `.github/ISSUE_TEMPLATE/bug_report.md`.
